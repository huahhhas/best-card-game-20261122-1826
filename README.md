**Emberfall** — an original duel card game. You, the Ember Warden, face Sable the Tidecaller with 24 life each. Spend mana to play strikes, guards, mends and draws from a 30-card deck of four winds — Ember ▲, Tide ●, Thorn ◆, Gale ✦ — told apart by colour and shape. Play two cards of the same wind in one turn to spark Resonance (+2). Sable telegraphs her plan each round, so you can read her and counter her. First life total to fall loses. Pure static files: no build step, no network requests, keyboard + mouse.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or open `game/index.html` in a desktop browser via any static server. Click a card (or press 1–7) to play it, Enter to end your turn, R to duel again. `?scene=title|table|win|loss&seed=N` stages a deterministic scene for screenshots.
